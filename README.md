A fast, dependency-free drop-in for makefun-site 1.0.0: `solve.js` builds the same static-site output tree byte for byte, with a hand-written Markdown renderer, a single-pass front-matter parser, and templates compiled to plain JavaScript functions instead of interpreted node by node.

## Run it

```sh
node main.ts
```

It reads every case from `/input/cases.json` (or `$MAKEFUN_INPUT_DIR`) and writes the answers to `/output/answers.json` (or `$MAKEFUN_OUTPUT_DIR`).
